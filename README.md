# AskWithoutFear

“It's okay not to know. It's okay to ask. Let's learn together.”

AskWithoutFear is a student-centred website prototype designed to help students identify what they find difficult, ask for support without fear of judgement, and build confidence through small learning steps and peer support.
✨ Features
1. 🎭 Anonymous Question Box — Students can submit a doubt anonymously or with a generic displayed label and choose the type of help they need.
2. 💚 “I've Had This Doubt Too!” — Students can show support for questions they relate to, helping make learning difficulties feel normal.
3. 🧠 Explain It Simply — Offers a prompt for a simple explanation and helpful next steps.
4. 🤝 Find Someone Who Understands / Reverse Help Match — Helps students think about topics they need help with and topics they could explain to a peer.
5. 🌱 Doubt-to-Confidence Tracker — Mark a topic as Still confused, Beginning to understand, or Understood.
6. 📚 Doubt Library — Search questions and sample explanations; update confidence status on a question.
7. 💖 The Doubt We Share — Highlights a relatable question and lets visitors show support.
8. 🌿 No Judgment Reminder — Reassures students that every question is welcome.
9. 🧠 Hidden Confusion Detector — A short self-check helps students identify whether they need theory, guided examples, basics, or practice explaining a concept.
10. 💚 “Nobody Asked, But Everyone Needed It” / Class Confusion Map — Displays a demo summary of shared learning needs and suggests a possible class support activity.
11. 🧩 Knowledge Bridge — Gives small guided steps for moving from a familiar idea to a harder concept.
12. 🌱 Confusion-to-Confidence Journey — Encourages students to name a difficulty, find a learning step, practise with support, and reflect on progress.
🧪 Running the prototype
This version is a self-contained HTML prototype. Open index.html in a browser, or use VS Code with the Live Server extension. If the file in this repository is named askwithoutfear.html, open that file instead or rename it to index.html.

No package installation is required for this prototype.
💾 Data and privacy note
The prototype uses the browser's localStorage for demonstration interactions. Posts and progress are saved only in the current browser and are not shared with other students. Hiding a display name is not the same as guaranteeing anonymity. A real multi-user version would need a backend, authentication choices, secure data handling, moderation/reporting, and clear privacy rules. The Class Confusion Map contains illustrative demo figures; replace them with actual consent-aware survey results before presenting them as real findings.
🌿 Connection to Eudaimonic Wellness
- Personal growth: Students can identify learning gaps and reflect on progress.
- Positive relationships: Peer learning encourages supportive connections.
- Competence: Small steps help students build confidence in difficult concepts.
- Autonomy: Students choose how to seek help and what learning step to try.
- Belonging: Shared doubts remind students that struggling is a normal part of learning.
